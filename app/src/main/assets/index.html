Thumbnails

↻ Naam + thumbnail refresh

Auto mode: PC par VJ Pad Bridge chalao, bas. Resolume → Preferences → OSC → OSC Input ON port 7000, OSC Output ON IP 127.0.0.1 port 7001, Webserver ON port 8080 (thumbnail).
Manual mode: Resolume → Preferences → OSC → OSC Input ON, port 7000. PC ka IP: cmd me ipconfig → IPv4 Address. Light/naam ke liye OSC Output ON, IP = upar likha phone ka IP, port 7001. Thumbnail ke liye Preferences → Webserver ON, port 8080.

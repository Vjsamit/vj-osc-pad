Resolume setup: Preferences → OSC → OSC Input ON, port 7000. PC ka IP: Windows me cmd kholo, ipconfig likho, IPv4 Address dekho. Clip naam/light ke liye OSC Output ON, IP = neeche likha phone ka IP, port 7001.

MIDI jaisa map karna (PADS / XY / FX tab): Resolume me upar menu Shortcuts → Edit OSC (Ctrl+Shift+O) dabao, Resolume me koi bhi control click karo (jaise Strobe effect ka Opacity), phir phone par pad/fader chalao. Map ho gaya. Wapas Edit OSC band karo. Bilkul MIDI learn jaisa.

PADS bhejte hain /vjpad/pad/1..16 (dabane par 1, chhodne par 0), faders /vjpad/fader/1..8 (0–1), XY /vjpad/xy/1/x aur /y, toggles /vjpad/toggle/1..6, FX faders /vjpad/fx/1..6.
